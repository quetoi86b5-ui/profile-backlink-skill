## Kế hoạch backlink chéo (làm sau khi các profile chính hoàn tất)
Nguyên tắc: mỗi profile đều trỏ về website chính diamondrise.com.vn, đồng thời trỏ sang các profile anh em ở mọi vị trí nền tảng cho phép (About/bio, mục links/websites, bài giới thiệu đầu tiên, link đính kèm trong ấn phẩm/tài liệu).

| Profile | Vị trí gắn link chéo | Trỏ tới |
|---------|----------------------|---------|
| About.me | Mục links (hub trung tâm — nền tảng này sinh ra để gom link) | Website + TẤT CẢ profile còn lại |
| Medium | Trang About + bài giới thiệu đầu tiên (ghim) | Website, WordPress, Spiderum, Substack, About.me, Facebook |
| WordPress.com | Trang Giới thiệu + menu/widget Links | Website, Medium, Spiderum, Substack, About.me, Facebook |
| Gravatar | Mục Websites + About | Website + các profile chính |
| Spiderum | Bio + bài giới thiệu đầu tiên | Website, Medium, WordPress, Facebook |
| Substack | Trang About của publication | Website, Medium, WordPress, Facebook |
| Tumblr | Blog description + trang tĩnh "Liên hệ" | Website + About.me (hub) |
| Quora | Profile bio + credentials | Website, Medium |
| Issuu / Scribd | Profile bio + trong tài liệu/brochure đăng lên | Website, About.me |
| Vimeo / Dailymotion / Flickr | Kênh/profile About + mô tả video/ảnh đầu tiên | Website, About.me |
| Blogger / Google Sites | Trang giới thiệu + blogroll | Website + toàn bộ profile chính |

Lưu ý khi làm:
- Ưu tiên gắn link ngay trong lúc hoàn thiện từng profile nếu nền tảng cho sẵn trường Links/Website — khỏi quay lại.
- Nền tảng chỉ cho 1 link website: để link website chính; link chéo dồn vào About.me làm hub.
- Sau khi chéo xong, cập nhật cột kiểm chứng vào bảng này (ngày + vị trí đã gắn).
